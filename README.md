# Camilly Braids — site comercial

Site estático feito com HTML, CSS e JavaScript, pronto para publicar no GitHub Pages.

## Arquivos
- `index.html` — conteúdo e estrutura do site
- `style.css` — cores, layout e responsividade
- `script.js` — menu mobile e ano automático no rodapé
- `images/` — fotos de tranças extraídas do PDF enviado e usadas na galeria e no destaque

## Como publicar no GitHub Pages
1. Entre no GitHub e crie um repositório, por exemplo `camilly-braids`.
2. Envie os três arquivos (`index.html`, `style.css` e `script.js`) para a raiz do repositório.
3. No repositório, entre em **Settings → Pages**.
4. Em **Build and deployment**, selecione **Deploy from a branch**.
5. Selecione a branch `main` e a pasta `/ (root)`, depois clique em **Save**.
6. Aguarde a publicação. O GitHub mostrará o endereço do site na própria página de Pages.

## Antes de publicar
- Confira se os links de WhatsApp, Instagram e TikTok estão corretos.
- A galeria e a foto de destaque usam as imagens incluídas na pasta `images/`, extraídas do PDF enviado. Mantenha essa pasta no repositório do GitHub para que as fotos apareçam no site.
- Fontes e imagem externas dependem de conexão com a internet.
- Confirme os modelos, preços, endereço/local de atendimento e regras de agendamento antes de acrescentar essas informações ao site.
